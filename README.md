

# 🎬 CineBook – Movie Ticket Booking Website

CineBook is a simple and responsive movie ticket booking website built using **HTML and CSS**. It provides users with an attractive interface to explore available movies, view ticket prices, select show timings, and book movie tickets.

This project was created to practice front-end web development concepts and improve my understanding of HTML structure and CSS styling.

## ✨ Features

- 🎥 Browse a collection of available movies.
- 💰 View movie ticket prices.
- 🕒 Choose from available show timings.
- 🎟️ Interactive movie booking interface.
- 📱 Responsive and user-friendly design.
- 🌙 Modern dark-themed UI.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, and responsive design.
